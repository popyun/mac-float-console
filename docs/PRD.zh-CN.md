# Mac 浮窗控制台 — 产品需求文档

简体中文 · [English](PRD.en.md) · [项目概览](../README.zh-CN.md)

- **状态：**可运行的 MVP／界面原型
- **平台：**macOS 14 及更新版本
- **当前范围：**实时系统指标和 Codex 额度；系统开关仅演示界面

## 1. 产品概述

Mac 浮窗控制台是一个菜单栏工具，通过小型浮窗把全机 CPU、内存使用率与当前账户的 Codex 额度放在一起。用户无需切换到「活动监视器」或账户页面，就能在工作时快速查看。浮窗可以置顶、锁定位置，也能缩成半透明状态条。

系统开关区展示未来控制功能的界面，与真实指标分开。**当前版本不会修改 macOS 的系统设置。**

## 2. 目标用户与场景

| 用户 | 要完成的事 |
| --- | --- |
| Mac 用户 | 在其他应用中工作时，随时留意 CPU 或内存是否变化。 |
| Codex 用户 | 查看短期与每周剩余额度，以及各自的重置时间。 |
| 小屏幕用户 | 仅保留关键百分比，尽量减少对桌面的遮挡。 |

## 3. 目标与范围边界

本阶段要让真实数据易于扫读、让浮窗尽量不打扰工作，并清楚区分实时读数与演示开关。Codex 额度沿用本机已有登录，不增加第二套登录流程，也不复制凭据。

本阶段不执行四项系统开关、不保存界面偏好、不编辑快捷功能、不展示历史曲线或进程明细、不管理 Codex 账户，也不提供已经公证的下载包。

## 4. 界面与交互

| 模式 | 尺寸 | 显示内容 | 窗口行为 |
| --- | --- | --- | --- |
| 默认 | 280 × 242 点 | 标题、CPU、内存、Codex 额度及重置时间、折叠的系统设置区 | 100% 不透明；默认置顶 |
| 展开设置 | 280 × 366 点 | 默认内容及四个演示开关 | 尽量保持窗口位置；100% 不透明 |
| 缩略 | 180 × 106 点 | CPU、内存、Codex 5 小时及周限额的剩余百分比、展开按钮 | 75% 不透明；隐藏重置时间 |

- 完整模式拖动标题区域；缩略模式拖动指标或额度区域。锁定位置后，两种模式都不能拖动。
- 缩略模式始终有可点击的展开按钮；双击和右键菜单也可恢复完整模式。
- 关闭按钮隐藏浮窗；菜单栏图标可重新显示，并提供缩略、锁定及退出入口。
- 演示开关开启为绿色、关闭为红色。状态仅保留到本次应用退出。
- 当前应用界面使用中文；README 与 PRD 提供中英双语，应用界面本地化属于后续工作。

## 5. 功能需求与验收标准

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| FR-01 | 展示全机 CPU 占用率。 | 根据相邻两次处理器采样的忙碌时间差计算，每 2 秒更新；首次差分完成前显示不可用标记。 |
| FR-02 | 展示物理内存使用率。 | 根据活动页、固定页和压缩器物理页计算整数百分比及已用／总量，每 2 秒更新；可回收的文件缓存不算已使用。 |
| FR-03 | 展示 Codex 额度。 | 启动时及每 5 分钟读取本机 CLI 账户，显示短期与周限额的剩余百分比和本机时区的重置时间；刷新按钮可立即查询。 |
| FR-04 | 真实呈现额度异常。 | 字段缺失时显示不可用，不推断为零；之后刷新失败时保留上次成功读数，并标明是旧数据。 |
| FR-05 | 缩略状态仍有用。 | 保留 CPU、内存及两项 Codex 剩余百分比，省略重置时间；整窗为 75% 不透明；有明显的恢复按钮。 |
| FR-06 | 控制浮窗位置。 | 图钉切换置顶，锁定后禁止拖动；关闭后可从菜单栏重新打开。 |
| FR-07 | 安全演示系统开关。 | 四项开关可点击并更新已开启数量，但不读取或更改系统设置、不保存状态；编辑入口不可用。 |

## 6. 数据口径、状态与约束

**CPU：**两次读取 macOS 处理器时间计数，把所有逻辑处理器的忙碌时间增量除以总时间增量。因此是全机 0–100% 的占用率，不是某个进程可能超过 100% 的多核百分比。

**内存：**从 macOS 虚拟内存计数读取活动页、固定页和物理压缩页，以安装的物理内存为分母。这个口径近似「活动监视器」的“已使用内存”，但底层分类和取整方式可能导致数值略有差别。

**Codex：**由本机已安装的 CLI app-server 处理登录。应用只发起读取额度的请求，优先使用多额度响应里的 Codex 项，并兼容旧版单项响应。剩余百分比为 100 减已用百分比，限制在 0–100 范围；重置时间使用本机时区。查询超时为 20 秒。应用不直接读取登录文件、不发起模型任务、不消耗额度重置次数。

当前界面状态只留在运行内存中；应用没有分析或遥测。CLI 获取额度可能需要网络。系统指标采样失败时，数值显示不可用，不伪造百分比。

## 7. 质量与验收

- 默认和缩略窗口不得裁切文字、百分比或按钮。
- 缩略或折叠系统设置后，指标仍持续采样。
- 模式切换时，在屏幕允许的范围内尽量保持右上角位置。
- 额度刷新不能阻塞界面、启动 Codex 对话或消耗重置次数。
- 公开仓库中的界面图片必须使用合成数据，不得包含个人额度截图。
- 验证 Release 构建、应用签名及配置文件；测试 CPU 差分与回绕、额度返回结构，并检查展开、默认、缩略三种渲染结果。

## 8. 后续待定事项

1. 为每个系统开关明确实际效果、所需权限、状态同步和保存方式，再接入真实执行。
2. 设计快捷功能编辑界面，并选择本地偏好存储格式。
3. 如需下载发行版，完善应用界面本地化和公证发布流程。

本文既描述已实现的 MVP，也明确标出范围边界。后续事项是产品规划，不代表当前版本已经具备这些功能。
